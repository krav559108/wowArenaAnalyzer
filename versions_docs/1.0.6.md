# 1.0.6

## Changes

- Fixed "Open source" and "Open AddOns" buttons in the manual addon install section — they were silently opening a non-existent path; now correctly resolves the addon folder in both dev and packaged builds, and creates the WoW AddOns directory if it doesn't exist yet.
- Fixed addon "connected" indicator not showing on fresh installs — the green status now reflects the current SavedVariables state immediately on app startup without requiring a WoW /reload to trigger it.
