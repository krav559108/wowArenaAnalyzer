# 1.0.5

## Changes

- Removed BlackHole audio capture feature — the audio device selector and all related UI/backend code has been removed.
- Fixed non-clickable FFmpeg download links in Windows onboarding; links now open the BtbN releases page in the browser.
- Added manual addon install fallback in Settings — "Open source" and "Open AddOns folder" buttons let users copy the addon themselves when auto-install fails.
- Added "Minimize to tray on close" setting — clicking × hides the app to the system tray instead of quitting; tray icon provides Show and Quit options.
- Added a Save button to the Settings header that flashes a confirmation (settings already auto-save on every change).
- Added a monitor selection step to onboarding on both macOS and Windows so users can pick which display to record.
- Windows now captures only the selected monitor instead of the full desktop spanning all screens.
- Added an Advanced Combat Logging step to onboarding with step-by-step instructions (Esc → Options → System → Network).
- Fixed videos not playing on Windows — file:// URLs with Windows backslash paths were invalid for the video element; paths are now normalized to the correct file:/// format.
- Solo Shuffle recordings are now grouped into a session folder (e.g. `2026-04-27_14-30-00_Zone_SoloShuffle/`) with per-round subfolders (`R1_WIN/`, `R2_LOSS/`, …). The session folder name includes the time to avoid collisions when multiple sessions are played in a day.
